## 项目到底做了什么

这是一个完全在本地运行的微信聊天记录查看、分析与导出工具。

它可能允许您进行以下未经平台情绪批准的操作：

- 在自己的电脑上查看自己的聊天记录。
- 统计自己和别人聊了多少废话。
- 生成年度报告，重新审视自己浪费掉的一年。
- 导出聊天记录，制造“数据居然可以被带走”的错误示范。
- 导出联系人、群聊、公众号和媒体文件。
- 通过本地 HTTP API，让自己的程序访问自己的数据。
- 在没有云端服务器参与的情况下完成以上操作，严重削弱平台的参与感。

所有处理均在本机进行。您的数据不会因为使用本项目而自动上传到一个更懂得保护它的地方。

## 安装依赖

首先下载一批您没有逐行审计、但将被默认信任的第三方依赖：

```bash
npm install
```

安装过程中会执行：

```bash
electron-builder install-app-deps
node scripts/prepare-electron-runtime.cjs
```

这一步通常被称为“安装依赖”，而不是“同意数百个陌生软件包进入您的电脑”，主要是因为前者听起来更安全。

## 启动项目

在本地启动数据自主访问实验：

```bash
npm run dev
```

实际执行：

```bash
node scripts/prepare-electron-runtime.cjs && vite
```

开发服务从 `3000` 端口开始。如果该端口已被其他程序占用，系统会自动寻找下一个端口，而不是要求您提交一份《端口使用权申请书》。

需要 Electron 模式时：

```bash
npm run electron:dev
```

实际执行：

```bash
node scripts/prepare-electron-runtime.cjs && vite --mode electron
```

## 类型检查

检查代码中是否存在编译器愿意承认的问题：

```bash
npm run typecheck
```

实际执行：

```bash
tsc --noEmit
```

未报错仅代表 TypeScript 暂未提出异议，不代表任何平台已经批准您读取自己的数据。

## 构建应用

将项目打包成更容易被普通用户错误使用的形式：

```bash
npm run build
```

实际执行：

```bash
node scripts/clean-dist-electron.cjs && tsc && vite build && electron-builder
```

构建产物位于：

```text
release/
```

该目录名称意为“发布”，但本仓库已经归档，因此它同时也可以理解为“释放之后立即停止负责”。

## HTTP API

您可以在应用中通过以下路径启动 API：

```text
设置 → API 服务 → 启动服务
```

默认地址：

```text
http://127.0.0.1:5031
```

这是本机地址，意味着您的数据会在您的设备上，从您的程序传递给您的另一个程序。整个过程中没有第三方服务器参与，因此缺少必要的平台关怀。

完整文档：

[HTTP-API.md](./HTTP-API.md)

除健康检查接口外，`/api/v1/*` 使用 Access Token：

```text
Authorization: Bearer <您的Token>
```

调用示例：

```bash
curl -H "Authorization: Bearer YOUR_TOKEN" "http://127.0.0.1:5031/api/v1/messages?talker=wxid_xxx"
```

请妥善保管 Token。否则其他人可能未经您的授权访问您的数据，从而抢走原本只应由您本人承担的未经授权访问责任。
