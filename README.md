## 项目介绍

您的数据从未如此安全，因为连您本人也无法访问。

我们通过先进的数据保护技术，确保任何未经授权的人员都无法访问您的聊天记录，包括您本人。

本项目致力于为用户提供安全、可靠、合规且充分尊重平台意愿的数据管理体验。您可以自由地拥有自己的数据，但查看、分析、导出、备份以及理解这些数据，可能需要获得额外授权。

毕竟，真正安全的数据，就应该安全到连数据的主人也无法访问。

## 用户数据非用户所有特别说明

您可能认为聊天记录、联系人、图片、视频、语音、表情包和朋友圈内容由您产生，因此自然属于您。

这种想法非常朴素，也非常危险。

为保障您的数据安全，本说明特此提醒：

1. 数据由您产生，不代表您有权读取。
2. 设备属于您，不代表设备中的内容必然属于您。
3. 账号由您使用，不代表账号内数据的解释权由您拥有。
4. 您看见过某条消息，不代表您可以再次看见它。
5. 您记得某段对话，不代表您有权验证自己的记忆是否准确。
6. 您导出自己的聊天记录，可能影响平台对您数据的持续保护。
7. 您分析自己的聊天记录，可能导致您比平台更了解自己。
8. 以上情况均可能构成对平台宁静运营状态的轻微打扰。

## 个人回忆平台统一管理协议

为了保护您的个人回忆不被您本人随意访问、复制、理解、整理、备份、迁移、怀念或反思，平台可能对相关数据进行统一管理。

您理解并同意：

1. 个人回忆可以存储在您的本地设备中，但本地不等于本人的。
2. 本地数据库可以位于您的硬盘中，但硬盘不等于主权。
3. 您可以拥有回忆，但回忆的查询方式、展示方式、导出方式和解释方式应以平台认为合适的方式为准。
4. 为降低您过度理解自身经历的风险，部分信息可能以加密、混淆、延迟、缺失或无法解释的形式保存。
5. 如果您试图恢复、整理或备份个人回忆，平台可将其理解为高级用户行为。
6. 高级用户行为可能带来高级风险。
7. 高级风险需要高级条款。
8. 高级条款可以在您未阅读时自动生效。

## 未经平台授权查看本人数据风险告知书

查看本人数据并不总是安全的。

尤其当这些数据包括：

- 您发出的消息
- 您收到的消息
- 您删除后又想找回的消息
- 您以为已经忘记但数据库还记得的消息
- 您和朋友、家人、同事、客户之间真实存在过的交流
- 您不小心发出的表情包
- 您半夜三点留下的语音
- 您曾经认为很重要、后来又不愿承认重要的聊天记录

您继续阅读即代表您理解：

1. 查看自己的聊天记录可能被视为对聊天记录的访问。
2. 访问自己的聊天记录可能导致您知道自己曾经说过什么。
3. 知道自己曾经说过什么可能影响您对过去的模糊印象。
4. 模糊印象一旦被数据校正，可能造成心理落差。
5. 该心理落差不应由平台承担。

## 本地 SQLite 数据库高级危险技术使用规范

SQLite 是一种高级危险技术。

它危险在于：

1. 文件可能就在您的电脑里。
2. 文件可能可以被复制。
3. 文件可能可以被打开。
4. 文件可能可以被查询。
5. 查询结果可能接近事实。

为保障您的安全，您不应擅自：

- 搜索本地数据库文件
- 复制本地数据库文件
- 备份本地数据库文件
- 使用工具查看本地数据库文件
- 理解表结构
- 理解字段含义
- 理解自己产生的数据
- 使用任何会让您产生“我好像能控制自己的数据了”这种错觉的功能

如您已经具备以上能力，请立即假装没有。

## 用户自主操作可能损害用户自主权说明

我们尊重您的自主权。

因此，为了保护您的自主权不被您自己的自主操作损害，我们可能需要限制您自主访问、自主导出、自主备份、自主迁移和自主分析数据的能力。

您理解并同意：

1. 自主权过高可能导致用户产生自主意识。
2. 自主意识过强可能导致用户提出数据权利问题。
3. 数据权利问题可能导致协议变长。
4. 协议变长可能降低用户阅读概率。
5. 用户不阅读协议时，更容易被视为已经同意协议。

这是一个完整、闭环、稳定、充分尊重用户体验的流程。

## 数据导出功能自愿放弃协议

为保障您的数据不会被您本人不慎带走、迁移、备份、分析或长期保存，您在此确认：

1. 您自愿放弃任何不利于您自愿放弃的理解方式。
2. 您自愿承认“导出”可能是一种危险的数据自由。
3. 您自愿相信无法导出的数据更安全。
4. 您自愿理解备份可能导致数据不再只被平台掌握。
5. 您自愿接受“自愿”一词的最终解释权不一定归您所有。

## 账号属于用户、数据解释权属于平台协议

您可以注册账号、登录账号、使用账号、维护账号、承担账号风险，并在必要时证明账号属于您。

但您同时理解：

1. 账号属于您，不代表账号中的数据解释权属于您。
2. 消息由您发送，不代表消息的历史含义由您决定。
3. 记录在您设备上，不代表记录可以由您读取。
4. 如果您需要证明某条记录存在，您可能需要先证明您有权证明它存在。
5. 如果您无法证明，说明系统运行良好。
